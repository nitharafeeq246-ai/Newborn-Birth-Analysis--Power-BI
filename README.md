# Newborn Birth Analysis

## Project Overview
- The Newborn Birth Analysis project is an interactive Power BI dashboard developed to explore newborn birth records and understand the relationship between maternal characteristics, pregnancy details, and newborn health indicators.
-The project uses the NC Births dataset (OpenIntro) to analyze birth-related information, identify patterns, and present meaningful insights through interactive visualizations.This is designed to make birth and maternal health data easier to understand through KPIs, charts, filters, and multiple analytical pages.

## Project Objectives
 The main objectives of this project are:

-Analyze newborn birth records and understand overall birth trends.
-Explore the distribution of newborns by gender.
-Examine birth weight and identify low birth weight cases.
-Understand the distribution of pregnancy duration.
-Analyze the relationship between maternal age and birth records.
-Explore the relationship between maternal smoking habits and newborn health indicators.
-Identify patterns in pregnancy duration and baby weight.

## Dataset Description

Dataset Name: NC Births – OpenIntro
Dataset Size:
Total Records: 1,000
Total Variables: 13

The dataset contains information about newborn births, maternal characteristics, pregnancy details, and health-related indicators.
The analysis focuses on variables related to:
Baby Weight
Baby Gender
Mother's Age
Pregnancy Weeks
Smoking Habits
Low Birth Weight
Pregnancy and Birth Details

## Tools Used
- Microsoft Power BI

## Dashboard Structure

The Power BI dashboard consists of four analytical pages.
#### 1. Home Dashboard
The Home page acts as the main navigation page of the project.
It provides an overview of the project and allows users to navigate between the different analytical dashboard pages.

### 2. Birth Overview Dashboard
This page provides an overview of newborn birth records and general birth-related statistics.
Key Performance Indicators (KPIs):
Total Birth Records: 1,000
Average Pregnancy Weeks: 38.33
Average Baby Weight: 7.10 lbs

#### Visualizations:
Birth Records by Gender
Low Birth Weight Distribution
Pregnancy Weeks Distribution
Birth Records by Mother's Age
Smoking Habit Distribution

### 3. Baby Health Dashboard

This page focuses on newborn health indicators and explores patterns related to baby weight and pregnancy duration.

#### Analysis Areas:
Baby Weight Distribution
Low Birth Weight Analysis
Pregnancy Duration
Birth Weight Patterns
Gender-based Birth Analysis
Relationship between Pregnancy Weeks and Baby Weight

### 4. Mother Insights Dashboard

This page focuses on maternal characteristics and their relationship with birth-related information.

#### Analysis Areas:
Mother's Age Distribution
Maternal Smoking Habits
Pregnancy-related Patterns
Maternal Characteristics
Relationship between Mother's Age and Birth Details

## Key Insights
The dashboard helps explore several important aspects of newborn birth data:
The overall number of birth records and average birth-related measurements.
The distribution of newborns based on gender.
Patterns in baby weight and low birth weight categories.
The distribution of pregnancy duration in weeks.
Differences in birth records across maternal age groups.
Smoking-related patterns within the dataset.
Relationships between pregnancy duration and newborn weight.
These analyses provide a better understanding of the dataset and help identify patterns in maternal and newborn health indicators.

## Conclusion
The Newborn Birth Analysis project demonstrates how Power BI can be used to explore healthcare-related datasets and communicate meaningful insights through interactive dashboards.
By analyzing birth records, maternal characteristics, pregnancy duration, and newborn health indicators, this project provides a structured overview of the patterns present in the NC Births dataset.
